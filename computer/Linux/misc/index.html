    Change the Hostname

    1. Open a terminal and run the following command, replacing your-new-computer-name with your desired hostname:

      bash sudo hostnamectl set-hostname your-new-computer-name

      Note: Hostnames should generally be lowercase, contain no spaces, and use only alphanumeric characters or hyphens, such as my-ubuntu-pc.

    2. To prevent network lag or unable to resolve host warnings when you run sudo commands, update the local hosts file.

      • Open /etc/hosts in a text editor:

      bash sudo nano /etc/hosts

      • Look for the lines at the top of the file. You should see something similar to:

      text 127.0.0.1 localhost 127.0.1.1 old-computer-name

      • Change old-computer-name on the second line to match your-new-computer-name exactly.
      • Save and exit the file by pressing Ctrl + O, then Enter, and finally Ctrl + X.
      • Verify the change:

      bash hostname

    Change the Username

    You cannot rename an account while you are actively logged into it. Create a temporary helper account first.

    1. Open a terminal and create the helper account:

      bash sudo adduser tempadmin sudo usermod -aG sudo tempadmin

      Follow the prompts to set a temporary password. You can skip the other details by pressing Enter.

    2. Log out of your current desktop session completely.

    3. On the login screen, select tempadmin and log in.
    4. Open a terminal in the new account.

    5. Run the following command, replacing oldname with your current username and newname with the username you want:

      bash sudo usermod -l newname -d /home/newname -m oldname

      • -l newname: Changes the actual login name.
      • -d /home/newname -m: Creates a new home directory with the new name and moves your personal files into it.

    6. Ubuntu creates a personal group for each user. Update the group name to match the new username:

      bash sudo groupmod -n newname oldname

    7. Log out of the tempadmin account.

    8. Log in to your newly renamed account. Your files and settings should be in the new home directory.

    9. Open a terminal one last time and delete the temporary account:

      bash sudo deluser --remove-home tempadmin

    Your account is now renamed, and the temporary helper account has been removed.
